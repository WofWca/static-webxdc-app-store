# WebXDC Apps Explorer

A WebXDC app store with no moderation.
Just upload your app to GitHub or Codeberg and you're live!

## How it works

It fetches and displays repositories that have the `webxdc-app` tag ("topic")
from GitHub and Codeberg,
plus the apps from the [original app store](https://webxdc.org/apps/)
(many of which don't have the `webxdc-app` tag).
As you can tell, that doesn't require running a server.
It's just a static page.
