WebXDC Apps Explorer

Liked an app? Star it to move it up the list!

    Don't know how to run these? Download Delta Chat or any other messenger that supports WebXDC, send the .xdc file to a chat and click "Start"!
    Alternatively, try it in the browser, without installing anything.

    Want to have your own WebXDC app here? Upload it to GitHub or Codeberg and add the webxdc-app tag (topic) to it, then make a release with a file named app.xdc. Done!
    Apps from the webxdc.org app store are listed too.
